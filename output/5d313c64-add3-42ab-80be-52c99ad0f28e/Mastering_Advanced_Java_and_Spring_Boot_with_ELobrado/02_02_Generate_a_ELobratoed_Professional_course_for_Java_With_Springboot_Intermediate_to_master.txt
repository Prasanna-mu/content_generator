### Mastering Advanced Java and Spring Boot with ELobrado: Security and Database Integration

In this lesson, we will take our understanding of Spring Boot to the next level. We will explore how to secure your Spring Boot application and integrate it with various databases like MySQL, PostgreSQL, and MongoDB. This lesson will cover security features, database integration, and best practices for creating robust, secure, and database-integrated applications.

#### Securing Your Spring Boot Application

Spring Boot provides several ways to secure your application. We will start by looking at annotations that can be used to secure our RESTful APIs. Here's a simple example:

```java
@RestController
public class SecurityController {

    @GetMapping("/secured")
    public String securedEndpoint() {
        return "You have access!";
    }

    @GetMapping("/unsecured")
    public String unsecuredEndpoint() {
        return "You do not have access!";
    }
}
```

In this example, the `/secured` endpoint is secured, and only authenticated users will have access. To secure endpoints with annotations, you need to configure security in `application.properties`:

```properties
security.basic.enabled=true
```

Spring Boot also supports HTTP headers for security. For instance, you can set the `Authorization` header:

```java
@GetMapping("/secured")
public ResponseEntity<String> securedEndpoint(@RequestHeader("Authorization") String authorizationHeader) {
    if (authorizationHeader != null && authorizationHeader.startsWith("Bearer ")) {
        return new ResponseEntity<>("You have access!", HttpStatus.OK);
    } else {
        return new ResponseEntity<>("You do not have access!", HttpStatus.UNAUTHORIZED);
    }
}
```

#### Database Integration with Spring Boot

Spring Boot comes with a variety of starters that make it easy to integrate with different databases. Let's look at how to integrate with MySQL and PostgreSQL.

**MySQL Integration**

First, add the `spring-boot-starter-data-jpa` dependency in your `pom.xml`:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>
```

Next, configure your database details in `application.properties`:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/mydatabase
spring.datasource.username=myuser
spring.datasource.password=mypassword
spring.jpa.hibernate.ddl-auto=create-drop
```

Spring Boot will automatically create the database schema. Remember to use `spring.jpa.hibernate.ddl-auto=create` when running the application for the first time.

**PostgreSQL Integration**

Similar to MySQL, you'll need to add the `spring-boot-starter-data-jpa` dependency. Configure your database connection:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/mydatabase
spring.datasource.username=myuser
spring.datasource.password=mypassword
spring.jpa.hibernate.ddl-auto=create-drop
```

Spring Boot can also handle MongoDB integration. Here's a simple example:

**MongoDB Integration**

Add the `spring-boot-starter-data-mongodb` dependency to your `pom.xml`:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-mongodb</artifactId>
</dependency>
```

Configure the MongoDB settings in `application.properties`:

```properties
spring.data.mongodb.uri=mongodb://localhost:27017/mydatabase
```

#### Handling Transactions and Data Persistence

When working with databases, transaction management is crucial. Spring Boot provides annotations like `@Transactional` to manage transactions. Here's an example:

```java
@Service
public class UserService {

    @Transactional
    public void createUser(String name) {
        User user = new User(name);
        userRepository.save(user);
    }
}
```

This ensures that both the creation of a new user and the database call are either all committed or all rolled back.

**Transaction Management with MongoDB**

For MongoDB, you can use the `@Transactional(propagation=Propagation.REQUIRES_NEW)` annotation to handle transactions:

```java
@Service
public class UserService {

    @Transactional(propagation=Propagation.REQUIRES_NEW)
    public void createUser(String name) {
        User user = new User(name);
        userRepository.save(user);
    }
}
```

This ensures that any transactions started within the `createUser` method are isolated from the current transaction.
