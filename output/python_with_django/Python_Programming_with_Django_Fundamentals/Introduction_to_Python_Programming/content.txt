### Introduction to Python Programming Basics

Python is an interpreted, high-level programming language known for its readability and ease of use. It is widely used in web development, data analysis, machine learning, and automation scripts. Here, we'll cover the basics of Python programming.

#### 1. Python Syntax
Python uses indentation to define blocks of code, unlike languages like C or Java, where blocks are defined by keywords. For example:
```python
if x > 5:
    print("x is greater than 5")
```
Python supports both camelCase and snake_case naming conventions. A common practice is to use snake_case for variable and function names.

#### 2. Variables and Data Types
Variables in Python are dynamically typed, meaning you don’t need to specify the type when you declare a variable:
```python
x = 5  # integer
y = "Hello, World!"  # string
z = 3.14  # float
```
Python supports several built-in data types including strings, integers, floats, and booleans. You can also create lists, tuples, and dictionaries.

#### 3. Control Structures
Control structures in Python include:
- **If-Else Statements**:
```python
if x > 10:
    print("x is greater than 10")
else:
    print("x is not greater than 10")
```
- **Loops**:
```python
for i in range(5):
    print(i)
```

#### 4. Python Philosophy and Best Practices
- **Readability over Readability**: Python encourages readability over readability, using clear and concise syntax. Use meaningful names for variables and functions.
- **Consistent Use of PEP 8**: Follow PEP 8, the official Python style guide, for a consistent code style. This includes naming conventions, indentation, and spacing.
- **Code Reusability**: Write reusable functions and modules to avoid duplication. This makes your code more maintainable and scalable.

### Practical Example: A Simple Calculator

Let's build a simple calculator that can add, subtract, multiply, and divide two numbers.

```python
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    if b == 0:
        return "Error! Division by zero."
    else:
        return a / b

print("Select operation:")
print("1. Add")
print("2. Subtract")
print("3. Multiply")
print("4. Divide")

choice = input("Enter choice(1/2/3/4): ")

num1 = float(input("Enter first number: "))
num2 = float(input("Enter second number: "))

if choice == '1':
    print(f"{num1} + {num2} = {add(num1, num2)}")
elif choice == '2':
    print(f"{num1} - {num2} = {subtract(num1, num2)}")
elif choice == '3':
    print(f"{num1} * {num2} = {multiply(num1, num2)}")
elif choice == '4':
    print(f"{num1} / {num2} = {divide(num1, num2)}")
else:
    print("Invalid Input")
```

This example demonstrates how to structure basic operations and handle user inputs in a simple console application. This lays a solid foundation for understanding how Python can be used in practical applications, including web development with Django.
