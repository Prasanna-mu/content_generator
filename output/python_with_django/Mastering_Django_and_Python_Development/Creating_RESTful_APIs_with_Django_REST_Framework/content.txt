### Building API Endpoints
First up, let’s talk about endpoints. Think of them as routes in your API. For instance, a GET request to /api/posts/ will fetch a list of all posts. In Django REST Framework, we create these endpoints using the `APIView` class from `rest_framework`.

```python
from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework import status
from .models import Post
from .serializers import PostSerializer

class PostList(APIView):
    def get(self, request):
        posts = Post.objects.all()
        serializer = PostSerializer(posts, many=True)
        return Response(serializer.data)

    def post(self, request):
        serializer = PostSerializer(data=request.data)
        if serializer.is_valid():
            serializer.save()
            return Response(serializer.data, status=status.HTTP_201_CREATED)
        return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)
```

This `PostList` class provides two methods: `get` and `post`, corresponding to the HTTP GET and POST requests.

### Handling Requests and Responses
Next, let’s handle different types of requests. For example, the `get` method fetches all posts, while the `post` method creates a new post.

```python
class PostDetail(APIView):
    def get(self, request, pk):
        post = Post.objects.get(pk=pk)
        serializer = PostSerializer(post)
        return Response(serializer.data)

    def put(self, request, pk):
        post = Post.objects.get(pk=pk)
        serializer = PostSerializer(post, data=request.data)
        if serializer.is_valid():
            serializer.save()
            return Response(serializer.data)
        return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)

    def delete(self, request, pk):
        post = Post.objects.get(pk=pk)
        post.delete()
        return Response(status=status.HTTP_204_NO_CONTENT)
```

Here, the `get` method fetches a single post, the `put` method updates a post, and the `delete` method removes a post.

### Securing Your APIs
Finally, let’s focus on securing our API. Django REST Framework provides various mechanisms to protect your API. One common approach is to use middleware to check if a request is authenticated.

```python
class AuthenticationMiddleware:
    def __init__(self, get_response):
        self.get_response = get_response

    def __call__(self, request):
        # Check if user is authenticated
        if not request.user.is_authenticated:
            return Response({'error': 'User not authenticated'}, status=401)

        response = self.get_response(request)
        return response
```

This middleware ensures every request must be authenticated. It’s crucial for maintaining API security.
