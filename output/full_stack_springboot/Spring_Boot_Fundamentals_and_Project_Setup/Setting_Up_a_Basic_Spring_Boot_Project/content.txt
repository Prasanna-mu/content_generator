In this lesson, students will learn how to set up a basic Spring Boot project using both the Spring Initializr and the Spring Boot CLI. They will start by creating a new project, configure necessary dependencies, and then move on to setting up a controller and creating a simple RESTful API.

### Creating a Basic Spring Boot Project Using Spring Initializr

1. **Open your browser** and navigate to the Spring Initializr (https://start.spring.io/).
2. **Fill in the form with the following details**:
   - **Project Name**: Enter a name for your project, e.g., "MyApp".
   - **Group**: Typically, this is set to "com.example".
   - **Artifact Name**: Use the same name as the Project Name.
   - **Packaging**: Select "jar" for a standalone jar file.
   - **Java Version**: Choose the latest stable version.
   - **Language**: Select the language for your project.
   - **Spring Boot**: Select the latest version.
   - **Spring Framework**: Select the latest version.
   - **Dependencies**: For a basic setup, add "Spring Web" to include RESTful services.
3. **Generate the Project**: Click on "Generate" and download the generated project.

### Setting Up a Controller and Creating a RESTful API

Once you have the project set up, let's configure a controller to handle HTTP requests.

1. **Navigate to the project directory**:
   ```
   cd MyApp
   ```
2. **Create a new controller**:
   ```sh
   mvn archetype:generate -DgroupId=com.example.myapp -DartifactId=myapp -DarchetypeArtifactId=maven-archetype-quickstart -DinteractiveMode=false
   ```
3. **Add a new Java class for the controller**:
   ```java
   package com.example.myapp.controller;

   import org.springframework.web.bind.annotation.GetMapping;
   import org.springframework.web.bind.annotation.RestController;

   @RestController
   public class MyController {

       @GetMapping("/greeting")
       public String greet() {
           return "Hello, Spring Boot!";
       }
   }
   ```

4. **Update the `pom.xml` file to add the Spring Web dependency**:
   ```xml
   <dependencies>
       <dependency>
           <groupId>org.springframework.boot</groupId>
           <artifactId>spring-boot-starter-web</artifactId>
       </dependency>
   </dependencies>
   ```

### Running and Testing Your Application

1. **Build and run your application**:
   ```sh
   ./mvnw spring-boot:run
   ```
2. **Access your API**:
   - Use a tool like Postman or cURL to send a GET request to `http://localhost:8080/greeting`. You should receive the message "Hello, Spring Boot!".

### Summary

In this lesson, you learned how to set up a basic Spring Boot project using Spring Initializr and the Spring Boot CLI. You configured dependencies, created a controller, and set up a simple RESTful API. By following these steps, you can now build more complex applications with Spring Boot.
