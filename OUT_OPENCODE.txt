Workflow Now
1. Agent generates lessons → saves lessons.json → refines → saves lessons_refined.json
2. Agent generates subtopics per lesson → saves each + subtopics_all.json
3. Checker validates all subtopics have required fields (title, description, estimated_chars)
4. If validation fails → loads from saved subtopics_all.json → re-validates
5. Only proceeds to content generation after validation passes
This ensures the agent never loses estimated_chars or description fields, with automatic recovery from saved intermediate outputs.
